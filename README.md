# 🚀 Exercícios e Lógica em JavaScript

Este repositório reúne meus estudos práticos e resoluções de problemas focados em **Lógica de Programação** e **JavaScript Moderno (ES6+)**.

---

### 🛠️ Conceitos Praticados
* **Estruturas de Dados:** Manipulação e acesso direto a Arrays e Objetos.
* **Funções:** Sintaxe limpa com *Arrow Functions* e retornos implícitos.
* **Operadores & Comparadores:** Validações lógicas rigorosas (tipagem com `typeof` e operadores de igualdade).
* **Controle de Fluxo:** Estruturas condicionais e loops de repetição.
